# Legacy Component Archive

이 폴더는 초기 개별 패널 분리 구현 시 작성되었던 레거시 컴포넌트 아카이브입니다.

- `settings-panel.ts`: SVG 변환 제어 패널 (초기 버전)
- `audio-settings-panel.ts`: 오디오 인코딩 제어 패널 (초기 버전)
- `renamer-settings-panel.ts`: 파일명 변경 규칙 제어 패널 (초기 버전)
- `cleaner-settings-panel.ts`: 리소스 스캐너 설정 패널 (초기 버전)
- `file-queue.ts`: 파일 대기열 UI (초기 버전)

> **참고**: 현재 프로덕션 빌드는 `src/batcher-app.ts` 통합 워크스페이스 및 `src/components/`의 활성 컴포넌트(`app-header`, `alert-modal`, `audio-timestamp-modal`, `cleaner-results-view`, `folder-tree-view`, `log-console`)를 사용합니다.
