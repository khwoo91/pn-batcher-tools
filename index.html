자주 묻는 질문

배처의 기술적 원리와 안전성에 대해 명쾌하게 답변해 드립니다.

배처 툴(Batcher Tools)은 대용량 SVG 벡터 이미지 변환(PNG/JPG), WAV/MP3 오디오 변환, 대량 파일 이름 일괄 변경(Batch Rename) 기능을 웹 브라우저 내에서 100% 로컬로 처리해 주는 스마트 유틸리티 도구입니다.

복잡한 개발 환경 세팅이나 프로그램 설치 없이 크롬이나 웨일, 에지 등 브라우저에서 즉시 작동하며, 다중 배율 내보내기(@2x, @3x), 오디오 비트레이트 세부 조절, 다채로운 정규식 치환을 지원합니다.

SVG는 무한 해상도 벡터이지만, 모바일 앱(iOS, Android)이나 웹에 배치할 때는 픽셀 기반의 비트맵 이미지(PNG)로 변환해야 합니다.

최신 스마트폰과 고해상도 레티나 디스플레이는 2배~3배 높은 픽셀 밀도(DPI)를 가집니다. 따라서 기본 1.0x 배율로만 변환하면 레티나 디스플레이에서 아이콘이나 이미지가 흐릿하게 뭉개질 수 있습니다. 배처에서는 1.0x(표준), 1.5x(HDPI), 2.0x(@2x 레티나), 3.0x(@3x 고해상도) 배율을 한 번에 추출할 수 있습니다.

기존 변환기는 사용자 파일을 외부 클라우드 서버로 업로드한 뒤 결과물을 다운로드받으므로, 사내 기밀 디자인이나 개인 녹음본이 서버에 저장되거나 유출될 위험이 있습니다.

배처 툴은 최신 WICG File System Access API 및 Web Worker를 활용하여 100% 사용자의 웹 브라우저 메모리 안에서 모든 변환을 끝냅니다. 파일이 외부 네트워크로 단 1바이트도 나가지 않으며 심지어 오프라인 상태에서도 정상 작동합니다.

실수를 방지하기 위해 3단계 안심 보호 장치가 마련되어 있습니다:

  • 실시간 미리보기: 실제 파일이 바뀌기 전 화면에서 결과 파일명을 눈으로 직접 대조합니다.
  • 단계별 실행 취소 (Undo): 직전에 잘못 적용한 규칙만 한 단계 뒤로 되돌립니다.
  • 전체 이름 복원 (Reset): 클릭 한 번으로 불러왔던 처음 원본 파일명으로 깨끗이 되돌립니다.

상업적 목적 사용 전면 무료: 배처 툴을 이용해 가공하거나 이름 변경한 결과물에 대한 소유권과 저작권은 100% 사용자 본인에게 있습니다.

오픈소스 라이선스(MIT, BSD)를 기반으로 구축되어 개인 포트폴리오뿐 아니라 유료 앱 판매, 게임 에셋 상용 배포 등 모든 프로젝트에 제약 없이 안심하고 사용하실 수 있습니다.

Frequently Asked Questions

Clear answers about Batcher's technology, security, and usage.

Batcher Tools is a smart local utility for batch SVG-to-PNG conversion, WAV-to-MP3 audio encoding, and mass file renaming right inside your browser.

Requires zero installation, supports multi-scale retina exports (@2x, @3x), precise audio bitrate control, and advanced regex substitutions.

SVG vectors look sharp at any resolution, but mobile apps (iOS, Android) require bitmap PNGs. High-density retina screens have 2x or 3x higher pixel densities, so exporting at 1.0x looks blurry. Batcher exports standard, @2x, and @3x scales simultaneously.

Traditional tools send files to remote servers, creating leakage risks for private graphics or sensitive audio. Batcher uses the WICG File System Access API and Web Workers so 100% of data processing occurs inside your device memory.

Batcher includes 3 layers of safety: Live Preview before applying changes, step-by-step Undo, and one-click Reset to restore original filenames.
